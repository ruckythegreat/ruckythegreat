## 👾 About Me

Hey, I'm **Rucky**. I just like building things, breaking them, and figuring out how they work under the hood. No fancy buzzwords—just a lot of trial, error, and caffeine. 

- 🎮 Making games (built a Unity 2D Roguelike from scratch).
- 📱 Shipping mobile apps like **Uangky** (a finance tracker in Flutter).
- 🧩 Wrote my own JS framework (**Rucky.js**) just to see if I could.
- 🔍 Sometimes I reverse-engineer APKs for fun.
- 🌐 Right now, I'm messing around with **FastAPI** and **React**.
